# Сборка приложения «САУ» в .exe для Windows

Проект уже настроен под Electron. Готовая конфигурация:
- `electron/main.cjs` — главный процесс приложения
- `electron/preload.cjs` — preload-скрипт
- `electron-builder.json` — настройки сборки установщика
- Иконка: `public/logo.ico`

---

## Что нужно установить (один раз)

1. **Node.js 20+** — https://nodejs.org/ (LTS-версия)
2. **Git** — https://git-scm.com/ (если будешь клонировать с GitHub)

Никакой Visual Studio или Rust ставить не нужно.

---

## Шаг 1. Получить код проекта

**Вариант А — через GitHub** (рекомендуется):
- В poehali.dev: **Скачать → Подключить GitHub** → авторизация → выбрать репозиторий
- На своём ПК: `git clone <url-репозитория>`

**Вариант Б — скачать архивом:**
- В poehali.dev: **Скачать → Скачать код**
- Распаковать в любую папку

---

## Шаг 2. Установить зависимости

Открой терминал (PowerShell или cmd) в папке проекта и выполни:

```bash
npm install
npm install --save-dev electron electron-builder
```

---

## Шаг 3. Добавить скрипты сборки в package.json

Открой `package.json` и в раздел `"scripts"` добавь:

```json
"electron:dev": "vite build && electron .",
"electron:build": "vite build && electron-builder --config electron-builder.json"
```

И добавь в корень `package.json` (на уровне с `"scripts"`):

```json
"main": "electron/main.cjs"
```

---

## Шаг 4. Собрать .exe

```bash
npm run electron:build
```

Сборка займёт 2-5 минут. По завершении установщик появится в папке:

```
dist-electron/САУ.exe
```

Это **установщик** — двойной клик, и приложение установится с ярлыком на рабочий стол и в меню Пуск.

---

## Шаг 5. Запуск без установки (для теста)

Если хочешь просто проверить, что приложение работает:

```bash
npm run electron:dev
```

Откроется окно с приложением — без создания .exe.

---

## Возможные проблемы

**«electron не является внутренней командой»**
Не выполнил `npm install --save-dev electron electron-builder`. Повтори шаг 2.

**Белый экран при запуске .exe**
Проверь, что `vite.config.ts` имеет `base: './'`. Если базы нет, пути после сборки сломаются. На poehali этот файл закрыт от редактирования — перед сборкой добавь `base: './'` вручную в скачанной копии.

**Ошибка «Cannot find module 'electron/main.cjs'»**
Не добавил `"main": "electron/main.cjs"` в package.json. Шаг 3.

**Антивирус ругается на .exe**
Это нормально для неподписанных установщиков Electron. Чтобы убрать предупреждения, нужен сертификат подписи кода (Code Signing Certificate, ~₽15-30к/год).

---

## Итог

После сборки у тебя будет один файл `САУ.exe` (~80-90 МБ) — это полноценный Windows-установщик, который можно отдавать пользователям. Они просто запустят его и получат рабочее десктоп-приложение со всем функционалом из браузера.
